# 验证材料

当前 25 项集成测试使用真实 MySQL 与 Redis：数据库回归 8 项、Redis 场景 15 项、Redis 连接失败场景 2 项。测试专用 SQL 活动为 900001–900010 和 900020；对应测试记录会被清理，展示活动 1–5 的订单保留。

Redis 正常场景使用 `lab2:test:redis:` 命名空间，商品测试 TTL 为 2 秒。故障场景连接无人监听的本机 16398 端口，验证商品读降级与库存写失败，不停止正在运行的 Redis。

通过 `python scripts/lab.py test` 执行；`verify_http.py` 对运行中的演示服务执行 18 项接口检查并保留一笔独立验证用户订单。异步与消息幂等测试在阶段 D 添加。
