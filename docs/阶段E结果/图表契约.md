# 阶段 E 图表契约

- 目的：用真实数据区分接口响应、提交完成和缓存路径；保留波动与长尾，不为某个版本预设性能优势。
- 证据链：图 1 为共同活动查询接口的响应吞吐与 p95；图 2 为同一批次的 HTTP 响应与数据库完成观察；图 3 为缓存版 MISS/HIT 的分布；图 4 为一轮异步累计受理与落单轨迹。
- 图型：n=3 的版本比较用原始轮次点、中位数、最小至最大范围，档位连线只辅助阅读；n=300 的缓存路径用箱线叠加全部点；时间过程用阶梯图。备选为 ECDF，但本次不重复展示同一分布。
- 版型：两个双面板定量图、两个单面板图；每个面板回答一个问题，不使用双纵轴或 3D。
- 后端：Python Matplotlib，固定随机种子；600 个缓存样本不伪称 600 次独立环境重复。
- 规范：课程报告通用，最终宽 6.8 英寸、高 3.2 英寸；9 pt 左右文字，Okabe–Ito 配色与不同标记；SVG 文字保留、PDF 字体嵌入、PNG 300 dpi，另有灰度预览。
- 统计口径：版本比较每条件 3 轮、缓存每条件 100×3；min–max 不是 CI，不标显著性；订单完成为约 100 ms 轮询的首次提交可见性上界。纵轴为对数时直接注明。
- 审计：先核对原始请求、错误、分组数、缺失与长尾，禁止删除离群请求；再做缺字/裁切程序检查和逐图视觉检查。最终只使用探针修正后的完整轮次。
