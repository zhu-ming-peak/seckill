| 项目 | 约定 |
| --- | --- |
| 项目名称 | Lab2 商品秒杀系统 |
| 架构 | 单应用分层，依次引入 MySQL、Redis、RocketMQ |
| Java / 构建 | Java 17 / Maven，UTF-8 |

阶段 B 本机实践及基础版已完成，RDS 入门实践待资源。下一阶段为 Redis；数据库版验证边界见 `数据库版设计与验证.md`。
